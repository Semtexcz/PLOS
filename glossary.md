# Glossary

**ID:** GLO-01 • **Stav:** předběžné, autoritativní definice pojmů pro v0.1. Anglické názvy jsou stabilní referenční názvy, české názvy jejich ekvivalenty. Další vztahy rozvádí [doménový model](03-architecture/preliminary-domain-model.md). Nejde o datový slovník atributů.

| Pojem | Význam v PLOS | Nezaměňovat s |
| --- | --- | --- |
| Value / Hodnota | Volená kvalita či směr jednání, který lze žít průběžně | Cílem, dosažitelným stavem nebo skóre osoby |
| Personal Principle / Osobní princip | Člověkem přijaté vodítko pro opakované rozhodování | Architektonickým principem P1–P11; osobní princip lze revidovat |
| Design Principle / Návrhový princip | Pravidlo pro návrh metodiky, zde P1–P11 | Osobním přesvědčením uživatele |
| Life Area / Životní oblast | Trvající kontext života, v němž vznikají potřeby péče a případně změny | Projektem nebo pevným seznamem povinných oblastí |
| Care Need / Potřeba péče | Vyjádření toho, co v oblasti potřebuje průběžnou pozornost či udržování | Automatickým úkolem nebo výkonovým cílem |
| Vision / Vize | Představa žádoucího celkového směru života, otevřená revizi | Závazným plánem či předpovědí |
| Scenario / Scénář budoucnosti | Alternativní možný vývoj použitý při zvažování cest | Provozním scénářem UC nebo závazkem |
| Strategy / Strategie | Provizorní soubor voleb o směru, cestách a tom, čemu se nevěnovat, včetně důvodů a předpokladů | Seznamem všech cílů nebo podrobným plánem |
| Assumption / Předpoklad | Tvrzení přijímané pro rozhodování, jehož platnost není jistá | Pozorováním nebo ověřeným faktem; ASM jsou předpoklady návrhu, doménové předpoklady patří uživateli |
| Experiment / Experiment | Ohraničený záměr získat zkušenost k určitému předpokladu či otázce | Zaručenou změnou života; nevyžaduje vždy samostatný projekt |
| Objective / Cíl | Vyjádření konkrétní žádoucí změny, kterou lze v příslušném horizontu posoudit | Hodnotou, projektem nebo pouze vykonanou aktivitou |
| Outcome / Výsledek | Stav nebo změna relevantní pro cíl; vždy rozlišujeme zamýšlený výsledek a pozorovaný výsledek | Výstupem práce nebo automatickým důsledkem dokončení projektu |
| Output / Výstup práce | Vytvořený artefakt nebo dokončená služba či činnost | Outcome; existence výstupu nedokazuje jeho účinek |
| Portfolio / Portfolio | Rozhodovací pohled na vybrané a kandidátní záměry a ostatní nároky, jejich souběh a důvody výběru | Pouhým seznamem projektů nebo duplicitní evidencí závazků |
| Project / Projekt | Ohraničený soubor navazujících činností směřující k rozpoznatelnému dokončení | Samotným cílem nebo trvalou péčí o oblast |
| Commitment / Závazek | Rozpoznaná odpovědnost něco vykonat, zajistit nebo udržovat; dobrovolně přijatá či uznaná jako existující povinnost | Libovolnou zachycenou žádostí; odmítnutí uznat povinnost ji samo neruší |
| Captured Input / Zachycený podnět | Ještě nevyjasněná žádost, informace, nápad nebo signál | Přijatým závazkem nebo aktivní prací |
| Next Action / Další krok | Konkrétní aktuálně proveditelné jednání v určitém kontextu | Abstraktním záměrem nebo automatickým slibem jej vykonat |
| Routine / Rutina | Vědomě udržovaný opakovaný způsob činnosti nebo péče | Nekonečným projektem nebo nutně automatickým návykem |
| Habit / Návyk | V kontextu ustálený vzorec chování; může být žádoucí i nežádoucí | Každou naplánovanou rutinou; pravidelnost sama neprokazuje automatizaci |
| Capacity / Kapacita | Dostupnost relevantního zdroje v daném horizontu a kontextu, s nejistotou | Motivací, prioritou nebo souhrnným skóre všech zdrojů |
| Planned Capacity / Plánovaná kapacita | Odhad dostupnosti použitý pro plán | Garantovanou budoucí dostupností |
| Actual Capacity / Skutečná kapacita | Dostupnost, jak ji lze zpětně nebo aktuálně posoudit z dostupné evidence | Skutečnou spotřebou; samotná nečinnost dostupnost nedokazuje |
| Allocation / Alokace | Zamýšlené vyčlenění určitého zdroje pro určitý nárok a horizont | Skutečným použitím nebo automatickým přijetím závazku |
| Plan / Plán | Revidovatelná hypotéza o výběru a uspořádání činností a alokací v blízkém horizontu | Neměnným slibem, strategií nebo záznamem skutečnosti |
| Conditional Response / Podmíněná reakce | Zvolená možná reakce na rozpoznatelnou překážku či situaci | Deterministickým automatickým pravidlem nebo úplnou metodou WOOP |
| Observation / Pozorování | Záznam či sdělení zkušenosti, události nebo stavu s omezenou jistotou | Výkladem příčiny, absolutní pravdou nebo rozhodnutím |
| Metric / Metrika | Volitelně definovaný způsob získání či interpretace opakovatelných údajů pro konkrétní rozhodovací otázku | Samotným údajem nebo cílem systému |
| Review / Reflexe a přezkoumání | Interpretace dostupné evidence vzhledem k záměrům a okolnostem pro další volbu | Pouhým reportem nebo auditem výkonu člověka |
| Decision / Rozhodnutí | Volba člověka včetně relevantního důvodu, případně rozhodnutí pokračovat či nic neměnit | Doporučením systému nebo samotným pozorováním |
| WIP / Rozpracovanost | Aktuálně zahájená a dosud neukončená práce v daném rozsahu pohledu | Vším, co je evidováno, nebo univerzálním limitem |
| Rolling Horizon / Posuvný horizont | Postupné zpřesňování nejbližšího plánu a revize vzdálenějších záměrů podle zkušenosti | Automatickým přesouváním všech restů do dalšího období |
| Traceability / Trasovatelnost | Schopnost vysvětlit relevantní původ a návaznost požadavku, volby či činnosti | Povinným kompletním stromem všeho jednání |
| Verification / Verifikace | Posouzení souladu artefaktů nebo systému se stanovenou specifikací | Důkazem skutečného přínosu uživateli |
| Validation / Validace | Posouzení, zda návrh odpovídá potřebám a funguje v zamýšleném použití | Pouhou kontrolou odkazů a syntaxe |

„Nárok“ je v této iteraci souhrnné označení potřeby zdrojů vyvolané záměrem, péčí nebo závazkem; není samostatný nový základní objekt. „Taktika“ frameworku 12 Week Year se podle kontextu PLOS vyjadřuje dalším krokem, rutinou či dílčím plánem, ne novou paralelní entitou. „Úkol“ je neformální výraz; normativní text místo něj rozlišuje Commitment a Next Action.
